Implementation and tradeoffs
The common private batch helper is /home/nikolai/workspace/lumina-main/rsema1d/src/codec/symbols.rs:6. It transposes a bounded 32-row tile, broadcasts coefficients across rows, partitions 64-byte chunk positions among workers, accumulates eight components in worker-local buffers, XOR-reduces partials, and returns exactly K results. Encoding calls it at /home/nikolai/workspace/lumina-main/rsema1d/src/codec/commitment.rs:122; the feature-gated benchmark wrapper is /home/nikolai/workspace/lumina-main/rsema1d/src/codec/mod.rs:31. Single-row scalar computation remains at /home/nikolai/workspace/lumina-main/rsema1d/src/codec/symbols.rs:188.
The prototype copies each transposed column to reused scratch for each nonzero component, calls Engine::mul, then XORs separately. The fused variants reuse input loads and nibble decomposition across eight outputs. Zero coefficients are skipped before logarithm lookup, rather than treating the zero logarithm sentinel as a multiplier.
Private variant source is preserved in commit c816f1a and target/rlc-exploration/private/source/rsema1d/src/codec/rlc_simd.rs:12. It still uses reed-solomon-simd tables and the existing RS implementation, but owns a 74-line module containing the unsafe AVX2 kernel in Lumina. Its checkpoint changes the crate policy from forbid(unsafe_code) to deny(unsafe_code) with a narrow module exception.
The dependency variant adds a provided object-safe Engine::mul_add8 method, a portable default using existing Engine::mul, DefaultEngine forwarding, and an AVX2 override. API: /home/nikolai/workspace/reed-solomon-simd/src/engine.rs:154. Runtime CPU guard: /home/nikolai/workspace/reed-solomon-simd/src/engine/engine_avx2.rs:77. Fused kernel: /home/nikolai/workspace/reed-solomon-simd/src/engine/engine_avx2.rs:523. Coefficients are raw field elements; empty slices are accepted; zero is a no-op; every output must match the input length; input stays immutable. Lumina retains forbid(unsafe_code): /home/nikolai/workspace/lumina-main/rsema1d/src/lib.rs:3.
Fork delta: 227 inserted lines in three existing source files, including tests. It applies directly to the 3.1.0 dependency base already in use. The production API was compiled and exercised on Rust 1.82 with default features and without default features. Backporting to other dependency revisions was not tested. The current integration is intentionally a local path patch at /home/nikolai/workspace/lumina-main/Cargo.toml:109; a remote fork was not created or published. A proper solution must replace that path with a pinned distributable dependency.
Fused worker scratch is 80*K_padded bytes plus a 2 KiB tile (80 KiB per worker and 1.25 MiB across 16 workers at K1024), excluding coefficients, returned values and scheduler bookkeeping. The prototype additionally uses a 2*K_padded-byte scratch column. Source allocation evidence: /home/nikolai/workspace/lumina-main/rsema1d/src/codec/symbols.rs:39 and :79.
